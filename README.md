## Featured Project — Gelişim Pusulası

**Gelişim Pusulası** is an AI-supported 360-degree performance evaluation and personalized development planning application, jointly developed by **Şevval Gül** and **Yağmur Ateş** as our undergraduate graduation project.

The application includes 360-degree performance evaluations, AI-assisted mentoring, personalized development plans, progress tracking, and HR analytics dashboards.

**Technologies:** C#, Windows Forms, .NET Framework, Microsoft SQL Server, Large Language Models (LLMs).
